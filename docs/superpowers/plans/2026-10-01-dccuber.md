# DCCUber obligatorio Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Completar Q-Learning, ejecutar los cinco experimentos obligatorios y conservar evidencia para que el estudiante redacte el informe.

**Architecture:** `TaxiAgent.py` implementa únicamente la política y actualización de la tabla. `train.py` contiene una función única de entrenamiento que sirve tanto al `main.py` original como a un ejecutor de experimentos con configuración explícita, semillas, CSV y gráficos. `main.py` y `test.py` se trasladan sin alterar sus bytes.

**Tech Stack:** Python, NumPy, Gymnasium Taxi-v4, Matplotlib, biblioteca estándar `csv/json/unittest`.
